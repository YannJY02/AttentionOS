# Work

Use this directory for active drafts, implementation notes, and non-final working material.

Working notes are not accepted decisions. Promote durable choices into `docs/decisions/` only as proposed decisions unless the user explicitly accepts them.

## Developer Todo

- `todo.md` is the only developer todo/intake queue in this repo.
- It is for early ideas and untriaged reminders only.
- Confirmed plans belong in `docs/plans/`.
- Durable decisions belong in `docs/decisions/`.
- Current recovery state belongs in `docs/governance/project-state.md`.
- Superseded working material belongs in `docs/archive/work/`.

Follow `docs/governance/development-document-lifecycle.md` when converting todo
items into prompts, blueprints, implementation plans, verification notes, audits,
or archived material.
